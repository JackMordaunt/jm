# branding

jm's mark and the hero lockup for the README, each in a light and a dark version.

| file | what it is |
|------|------------|
| `mark-{light,dark}.svg` | the mark alone: small packages stacked into a program, yours the blue one on top |
| `hero-{light,dark}.svg` | the mark and the jm wordmark |

Ink is `#1c1b1a` on light and `#f0eee8` on dark; the accent is `#2f7fd0` on light and
`#5aa2ea` on dark. The wordmark is JetBrains Mono Bold, named rather than embedded, so a
renderer without it falls back to its own monospace.

The screenshots in `docs/images` are kitchen pages rendered headlessly:
`just material-png Buttons`, `just fluent-png Button` and `just primer-png Button Dark`.

The jm name and mark are not covered by the code licence. Use them to refer to the project,
not to imply endorsement or to brand a fork.
